# Milind Juttiga — portfolio

Personal portfolio site for Milind Juttiga, built with Jekyll and Sass and deployed through GitHub Pages.

## Local development

This project has no application dependencies. With Jekyll installed, run:

```sh
jekyll serve --livereload
```

Then open `http://localhost:4000`.

## Structure

- `index.md` — homepage, profile, expertise, and experience
- `projects.md` — professional work and side projects
- `contact.md` — contact details and social links
- `_layouts/default.html` — shared document shell and navigation
- `_sass/_style.scss` — responsive visual system
- `milind.jpeg` — profile image
